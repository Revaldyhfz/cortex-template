Cortex for Claude Code

Setup is done.

Claude Code now remembers your work between sessions, saves every conversation as a note you can read, follows a few house rules, and refuses a short list of dangerous commands.

One thing first: restart Claude Code. Rules and hooks only load when it starts. Then say personalise my Cortex setup, and it will fill in your profile by asking a few questions.

Try these first

Type each one into Claude Code. Plain words work too; these are just the shortest way in.

  1. /boot

    Start of a session. Claude reads your notes and tells you where you left off. On a fresh install it will say there is nothing yet, which is correct.

  2. save state

    End of a session. Writes a short checkpoint (done, decided, open, next) so tomorrow's session can pick up cold.

  3. /prompt make a habit tracker

    Before building anything vague. Claude asks a few questions, shows you the full spec, and only then writes code.

  4. /research <your question>

    Before a choice you would have to defend. Finds what practitioners actually do and regret, then saves a decision note to your vault.

  5. open the file with the error and fix it

    With VS Code open. Through the Sidekick extension, Claude can see your Problems panel and terminals, open the file, fix it, and show you the diff.

What's installed

Everything is plain Markdown and small Node.js scripts. Read any of it, edit any of it, delete what you don't want.

Memory and capture

Session capture
Every conversation is saved as a readable note in your vault, automatically.
Live state notes
One auto-updated note per chat: latest summary, recent asks, files changed.
Memory surfacing
When your prompt matches something Claude memorised, the full note is put in front of it.
Memory layers
Rules, memory, knowledge, states and sessions, each with one job, so facts don't drift.

Rules

Answering
Big answers open with a progress table, then plain English, then a short summary.
Receiving
A short request gets a few questions and a spec before any code.
Discretion
What Claude does alone, what it tells you after, what it asks first, and what it never does.
Studio
When to work solo, with a few helpers, or as a full team of agents.
Environment, tooling
Machine hazards and which tool to reach for. Has a section for your own machine.

Skills

/boot
Where did we leave off.
/save-state
Curated checkpoint at the end of a session.
/prompt
Turns a one-line idea into a real spec.
/research
Evidence-first decision notes.
/council
Five advisors stress-test a decision. Uses more subagents, so it costs more.

Hooks and guardrail

Guardrail
Blocks wiping your home folder, curl … | bash, force-push and reading private keys; asks before email or config edits.
Context watch
Warns as the conversation fills up, and when Claude repeats the same command.
Post-compact
After a long chat is compacted, reminds Claude which files it already changed.
Audit log
Every block is written to cortex/state/guardrail-blocked.log.

VS Code Sidekick

Editor tools
Claude can read your open file and selection, open a file at a line, and read the Problems panel.
Terminals
Runs commands in a visible "Claude" terminal and reads output from yours, like npm run dev errors.
Live edits
Files Claude changes open beside you with the new lines highlighted, plus Review diff and Revert.
Terminal safety
Every command Claude runs there is checked by the same guardrail first.

Autonomous mode and studio

/aw
Keeps working through a queue while you're away. Never pushes, spends or deletes; parks decisions for you in BLOCKERS.md.
/studio
Runs a big task like a small company: research, a lead per team, independent reviewers, one plan.

Tools Claude can use

reels
Paste an Instagram reel, TikTok or YouTube Short link and Claude watches it: caption, a timestamped transcript and a grid of frames. No login.
Playwright
A browser Claude drives by itself, for testing your web app or reading a page that needs clicks.
context7
Up-to-date library documentation, so code matches the version you actually use.
GitHub
Issues, pull requests and code search. Needs the GitHub CLI, logged in once with gh auth login.
Updates
At the start of a session Claude checks GitHub for a newer Cortex. If there is one, it tells you and installs only when you say yes.

Switch on in the Claude app

These come with Claude itself, so the installer cannot turn them on. Each takes a minute, once. Ask Claude "help me turn on Claude in Chrome" and it will walk you through.

Claude in Chrome
Claude works in your own Chrome, with your logins: reading pages, filling forms, testing your site. Install the Claude extension from the Chrome Web Store, then sign in.
Computer use
Claude can see your screen and use desktop apps. Turn it on in the Claude desktop app, then allow it in macOS System Settings under Privacy & Security (Accessibility and Screen Recording). It asks before using each app.
Built-in browser
A browser pane inside the Claude desktop app, for previewing what you build. Nothing to install.
Connectors
Gmail, Google Drive, Calendar and others, through your own account at claude.ai under Settings, then Connectors.

Undo

From the folder you installed from, {{REPO_DIR}}, run:

node uninstall.mjs

It removes only what Cortex added and moves those files to a dated backup folder instead of deleting them. Your vault is never touched. Add --dry-run to preview first.
